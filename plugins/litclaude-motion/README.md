# litclaude-motion

This plugin packs LitClaude's short typographic films and silent README cover loops, rendered and checked frame by frame. It holds skills only: no hooks, no background scripts and no network calls of its own. Each skill names the files it writes and checks its own output before it reports. The full LitClaude package, with the planning and review routine that ties these skills together, installs with `npx @litfamily/litclaude install`. Source and documentation: https://github.com/wjgoarxiv/litclaude.
