# Annotations and callouts

Use annotations to explain an exception, boundary, or implication that cannot be shown by the primary geometry alone.

- Use one concise sentence, attached to the relevant edge or group.
- Draw a thin leader only when proximity does not make the target clear.
- Keep the note outside node text so it does not change the node's name.
- Use the same sans face as the diagram. Do not introduce a serif callout font.
- Mark a threshold, warning, or uncertainty with words and shape as well as color.
- Avoid speech bubbles, stickers, floating notes, or duplicate captions.

In the full-editorial variant, use one takeaway line and a compact legend when either helps the reader. A caption that merely repeats the title should be removed.
