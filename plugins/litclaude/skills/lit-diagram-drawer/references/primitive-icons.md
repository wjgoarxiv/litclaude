# Icon marks

Icons support a label; they do not replace one. Use a small, consistent set of simple marks so a reader can recognize a role without decoding a logo catalog.

## Selection

- Prefer an explicit noun label when space permits.
- Choose the icon by meaning, not by visual resemblance alone.
- Use the same icon for the same role throughout one diagram.
- Pair a brand mark with a text label. Do not rely on its silhouette or brand color to identify a system.
- Use geometric placeholders for an unnamed organization or vendor. Never invent a logo.

## Drawing

- Use a 20–24px viewBox and a consistent stroke of about 1.5px at that size.
- Keep icon paths single-color using currentColor. Use the diagram's ink or muted token.
- Align icons to the label baseline and reserve at least 8px of clear space around them.
- Use fill marks only when the source icon is designed for a filled silhouette.
- Hide redundant decorative icons from assistive technology; keep an adjacent visible text name.

The icon sheet in assets/icons.html demonstrates the shipped marks and their source groups. NOTICE records Tabler, Simple Icons, log-z/logos, Devicon, one-off sources, and trademark restrictions. Do not add an icon to the sheet without adding provenance.
