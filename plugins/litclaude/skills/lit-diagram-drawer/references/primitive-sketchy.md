# Sketch-derived material

Sketches and whiteboards are sources of structure, not a style to copy automatically.

- Preserve only the user-intended labels, grouping, direction, and constraints.
- Rebuild the result on a fresh 4px grid using the selected diagram type.
- Do not imitate hand-drawn jitter, rough marker strokes, source colors, or the original coordinates unless the user specifically asks for a sketch look.
- Ask about empty or ambiguous boxes instead of inventing their meaning.
- Report what was merged, collapsed, or dropped when the import loses information.

A playful hand-drawn finish is an explicit style choice. Keep it legible, preserve contrast, and do not let sketch texture blur arrows, text, or trust boundaries.
