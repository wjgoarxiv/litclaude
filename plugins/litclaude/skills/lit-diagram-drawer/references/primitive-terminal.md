# Terminal-window treatment

The terminal treatment is a specialized frame for a command sequence or code sample. It is not a general dark theme and should not turn an architecture diagram into decorative terminal chrome.

- Use a flat charcoal frame with a single warm accent.
- Keep the command readable as selectable text in the HTML source and as live SVG text in the image.
- Distinguish prompt, command, and result with labels or indentation; color alone is insufficient.
- Omit fake window controls, blinking cursors, unexecuted status symbols, and output that was not provided or verified.
- Keep the frame subordinate to the actual command and its result.

When a system diagram includes a terminal snippet, use the ordinary diagram skin and limit this treatment to the snippet itself.
