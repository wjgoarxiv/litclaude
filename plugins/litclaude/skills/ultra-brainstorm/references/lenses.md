# Lenses

One line per lens, passed to the idea agents in this order. Agent `i` takes lens `i mod 32`, so a run
of 100 agents uses every lens at least three times with different seeds. Keep the list at 32 or more
and keep each line a question an agent can act on alone.

1. Inversion: what would the opposite aim look like, and which part of it is right?
2. Constraint removal: drop one real constraint; what becomes possible, and what survives with it back?
3. Analogy: which unrelated field solved this shape of problem, and what mechanism can be borrowed?
4. Extreme user: design for the most demanding, most novice or most hurried person.
5. Subtraction: what can be removed so the rest works better?
6. Combination: join two existing things that are never joined.
7. Time shift: how would this be done ten years ago, or ten years from now?
8. Resource swap: replace the scarce resource with one that is plentiful.
9. Worst idea flipped: write the worst answer, then reverse its worst trait.
10. Reframe: answer a better question than the one asked.
11. Cheapest version: what works by tomorrow for almost no cost?
12. Most ambitious version: what would it take to make this ten times better?
13. Null option: what happens if nothing is done, and when is that best?
14. Automation: what could run on its own without anyone deciding?
15. Manual first: what would a person do by hand before any tool exists?
16. Defaults: which default, if changed, changes everyone's behaviour?
17. Failure mode: how does this fail, and what design makes failure harmless?
18. Trust and safety: what would make a careful user say yes immediately?
19. Measurement: what can be counted, and what idea follows from counting it?
20. Feedback loop: where can the result feed back into the next attempt?
21. Ecosystem: who else touches this, and what would they build on it?
22. Scale down: what is the single-person, single-day version?
23. Scale up: what changes at a thousand users or a thousand items?
24. Different medium: text, voice, picture, sound, motion, physical object.
25. Different place: where else could this happen (terminal, phone, paper, meeting)?
26. Incentives: who is rewarded, and what if someone else were?
27. Sequence: change the order of the steps; what improves?
28. Batch versus stream: do it all at once, or continuously in small pieces?
29. Borrow a ritual: a checklist, a ceremony, a habit from another craft.
30. Teach it: what would make this easy to explain to a newcomer?
31. Remove the expert: what if nobody involved knew the field?
32. Contrarian: which belief everyone holds here is probably wrong?
