# litclaude-design

This plugin packs LitClaude's interface design and build guidance, plus a visual QA pass over pages that already exist. It holds skills only: no hooks, no background scripts and no network calls of its own. Each skill names the files it writes and checks its own output before it reports. The full LitClaude package, with the planning and review routine that ties these skills together, installs with `npx @litfamily/litclaude install`. Source and documentation: https://github.com/wjgoarxiv/litclaude.
