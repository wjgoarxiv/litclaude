# Code of conduct

LitClaude welcomes constructive participation across experience levels and
backgrounds. This code applies to project issues, pull requests, reviews, and
other project-maintained spaces, and to people representing the project there.

Discuss the work with care. Explain technical disagreement with evidence, accept
corrections, and give others room to learn. Respect names, identities, privacy,
and reasonable requests to stop an interaction. Avoid harassment, discriminatory
language, threats, sexual attention, impersonation, and publication of another
person's private information. Repeated disruption or retaliation after a report
is unacceptable.

Maintainers may edit or remove disruptive material, close or lock a discussion,
restrict participation, or remove a participant when needed to protect the
community. Responses should reflect the behavior, its impact, and repetition;
maintainers should explain a decision when doing so does not expose private
information or create further harm.

To report a concern, use a minimal, non-sensitive message in the
[project issue tracker](https://github.com/wjgoarxiv/litclaude/issues) to request a
private channel from a maintainer. Do not post names of affected people, private
messages, or evidence of abuse publicly. No dedicated confidential conduct
address is published here; wait for a confirmed private route before sharing
sensitive details. For abuse occurring on GitHub, its built-in reporting controls
are also available. If a report concerns a maintainer, request review by another
maintainer where one is available; a separate appeals panel is not promised.

Security vulnerabilities use the [security reporting process](SECURITY.md).
Ordinary product questions use [support](SUPPORT.md).
