# LitClaude directory packs

This branch holds the LitClaude skill packs listed in the Claude plugin directory: diagram, design, motion and craft. Each folder under `plugins/` is one plugin with skills only, no hooks. The branch is generated from `main`; edit LitClaude on `main`, never here.

The full LitClaude, with the planning, execution and review routine and every skill, lives on [`main`](https://github.com/wjgoarxiv/litclaude) and installs with `npx @litfamily/litclaude install`.
